# Ksheera-Sagara 🥛
### Dairy Profit Tracker App for Karnataka Farmers

## About
Ksheera-Sagara is an Android app that helps dairy farmers calculate their actual monthly profit or loss by tracking daily milk income and all related expenses.

## Problem Statement
Dairy farmers receive a daily milk slip but never calculate their real earnings after subtracting feed, medicine, and labor costs. This app brings financial clarity to small-scale dairy farmers.

## Features
- 📊 Profit/Loss Dashboard with Green/Red indicator
- 🥛 Daily Milk Entry (Liters, Fat%, Amount)
- 💸 Expense Tracking (Fodder, Medical, Labor, Electricity)
- 🐄 Cow-wise Profit Analysis
- 📈 Expense Pie Chart
- 🤖 Gemini AI Cost Reduction Suggestions
- 📄 PDF Export of Monthly Report
- 🔐 Login with Profile Management
- 📱 Works fully offline using Room Database

## Tech Stack
- Language: Kotlin
- Database: Room Database (SQLite)
- AI: Gemini API
- PDF: iTextPDF
- UI: Material Design with Navigation Drawer
- Min SDK: Android 7.0 (API 24)
